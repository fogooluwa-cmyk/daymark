# Daymark style lock

Established: 2026-11-19. Source: PRD, requested redesign, and reference review.

## Palette

- The workspace uses a dark ink canvas with raised charcoal surfaces, crisp cool-gray borders, and warm white text for long task lists.
- Daymark blue carries primary actions and focus states. A restrained amber sun mark is used as a small brand accent.
- Completion uses a muted green signal. Red is reserved for destructive actions and errors.
- Light theme stays available with cool off-white canvas, white surfaces, deep ink text, and the same blue and amber identity.
- Maintain readable contrast for body text and controls; decorative marks are never the only status cue.

## Typography

- System sans stack keeps the MVP fast and readable.
- Use a compact uppercase eyebrow only for secondary context. Page titles are clear and sentence case.
- Task text takes priority over decoration. Keep supporting labels smaller but comfortably legible.

## Shape and spacing

- Desktop uses a narrow persistent sidebar and a centered, bounded task workspace.
- Cards and task rows use subtle borders and moderate rounded corners; avoid oversized pills and heavy shadows.
- Mobile replaces the sidebar with a fixed bottom navigation and preserves a comfortable quick-add touch target.
- Dense settings and list rows remain separated with spacing and contrast rather than extra chrome.

## Structure and motion

- The app shell focuses on one Today canvas, clear daily progress, and a fast task input.
- Upcoming and Completed are direct, predictable list views.
- The public landing page introduces the product with a useful preview of the actual task workflow.
- Motion is brief and functional. Respect reduced-motion preferences and provide visible focus states.

## Direction

- Mood: focused, warm, and composed; useful for a busy person without turning the day into a project board.
- Reference qualities: Upstash's clear product storytelling, Conductor's confident workspace preview, and personal task apps' direct reminder and Today patterns.
- Do not copy reference brand assets, text, or page layouts. See `reference-board.md` for source notes.
